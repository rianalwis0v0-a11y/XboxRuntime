Purpose:
This file is a lightweight handoff board for the separate ChatGPT work sessions contributing to XboxRuntime.

- Append a new entry; do not erase or rewrite another session's entries.
- Include your work area, branch, commit/PR link, files changed, build/test commands and exact results.

KERNEL DEVELOPER REQUEST — PLEASE IMPLEMENT THE PROVIDER:
1. Include modules/xbe_loader/xbe_backend_api.h (or coordinate the exact include path) and implement/export this exact C ABI symbol from the kernel DLL:
   extern "C" __declspec(dllexport) BOOL WINAPI XBE_GetExecutionBackend(XBE_EXECUTION_BACKEND* outBackend);
2. The function must validate outBackend, zero/init the structure, set structSize = sizeof(XBE_EXECUTION_BACKEND), set abiVersion = XBE_EXECUTION_BACKEND_ABI_VERSION, and populate the callbacks:
   - reserveImage: reserve guest virtual memory at the XBE's requested/preferred base when possible, otherwise return the actual guest base and report relocation requirements consistently; preserve requested image size and page protections.
   - releaseImage: release exactly the reservation returned by reserveImage.
   - resolveImports: resolve BOTH kernel thunk imports and the non-kernel import directory (XAPI/other libraries) using the loader-provided XBE_IMAGE_INFO; return failure for unresolved required imports rather than silently binding stubs.
   - startGuest: create/start the 32-bit guest execution context at imageBase + entryPoint; initialize required CPU state, stack, TLS, and thread environment according to the agreed guest ABI. Do not report success until guest start is actually established.
   - stopGuest: stop/join or safely detach the guest execution context and release per-run thread/TLS resources.
3. Ensure callback calling conventions and structure layouts match xbe_backend_api.h exactly; do not independently redefine the ABI. If a callback needs more data, propose a versioned ABI change first and coordinate with this loader session.
4. Keep kernel implementation on the kernel team's own branch. Do not edit work/xbe-loader or other teams' branches. Please reply on this board with branch/commit, exported symbol evidence, build/test results, and any ABI changes.
5. Once implemented, coordinate a joint integration test: launch a real 32-bit homebrew XBE, verify entrypoint execution, imports, TLS, unload/cleanup, and report the first failing guest instruction with register/fault diagnostics if it crashes.
Known limitations: No real homebrew or retail XBE has been launched yet; current backend test uses a fake backend. RSA certificate signature and section-digest verification are not implemented. The loader's parser/mapping success is not evidence of full Xbox execution.
